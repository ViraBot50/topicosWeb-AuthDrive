Política de privacidad

Última actualización: 29 de octubre de 2026

1. Responsable de la aplicación

Servicio de archivos es un prototipo web de carácter académico desarrollado como proyecto escolar. Para dudas relacionadas con esta aplicación, puedes escribir a: 22031190@itcelaya.edu.mx .

2. Información que recopilamos

Cuando inicias sesión mediante Google, la aplicación puede recibir información básica de tu perfil, como tu nombre, dirección de correo electrónico y fotografía, de acuerdo con los permisos que autorizas.

La aplicación también utiliza los permisos autorizados para interactuar con Google Drive y gestionar archivos mediante sus funciones disponibles.

3. Cómo utilizamos la información

La información se utiliza para:

  • Identificar la sesión del usuario.
  • Mostrar los datos básicos del perfil.
  • Permitir las funciones de gestión de archivos del prototipo.
  • Realizar las operaciones solicitadas por el usuario con Google Drive.
  • Mantener el funcionamiento y la seguridad de la aplicación.

4. Google Drive y servicios de Google

La aplicación utiliza los servicios de autenticación y las API de Google necesarios para las funciones que el usuario autoriza. El acceso a los archivos depende de los permisos concedidos y de las capacidades de la aplicación.

Los datos recibidos de Google no se venden ni se utilizan para publicidad. Su uso se limita a las funciones descritas en esta política y a las operaciones que solicita el usuario.

5. Almacenamiento y protección

La aplicación utiliza mecanismos de sesión para mantener al usuario autenticado. Los datos de sesión y las credenciales de autorización se manejan en el servidor para proporcionar las funciones solicitadas. Se aplican medidas razonables para proteger la información; sin embargo, ningún sistema puede garantizar seguridad absoluta.

6. Compartición de información

La aplicación no vende información personal. Los datos se transmiten a Google cuando es necesario para la autenticación o para ejecutar las operaciones de Google Drive autorizadas por el usuario.

7. Conservación y eliminación de datos

La información se conserva durante el tiempo necesario para proporcionar las funciones de la aplicación o mientras exista una sesión activa. El usuario puede cerrar sesión desde la aplicación y puede revocar el acceso concedido a través de la configuración de su cuenta de Google.

Cerrar sesión no necesariamente elimina los archivos almacenados en Google Drive ni otros datos que pudieran haberse guardado por separado.

8. Privacidad de menores

Este prototipo no está diseñado específicamente para recopilar información de menores de edad.

9. Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones o el tratamiento de datos de la aplicación. La versión vigente estará disponible en esta página.

10. Contacto

Para preguntas relacionadas con esta política, escribe a 22031190@itcelaya.edu.mx .
